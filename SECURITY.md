# Guvenlik Politikasi (SECURITY)

T.C. Kastamonu Belediyesi olarak, kentsel bilisim sistemlerimizin, e-belediye servislerimizin ve kamuya acik dijital varliklarimizin guvenligi birincil onceligimizdir.

## Desteklenen Surumler ve Servisler

| Bilesen / Proje | Destek Durumu |
| :--- | :--- |
| kastamonu-akilli-sehir-platformu | Aktif Guvenlik Destegi Saglanmaktadir |
| E-Belediye Entegrasyon Servisleri | Aktif Guvenlik Destegi Saglanmaktadir |
| CBS ve IoT Telemetri Aglari | Aktif Guvenlik Destegi Saglanmaktadir |

## Guvenlik Acikliklarinin Bildirilmesi

Projelerimizde veya altyapilarimizda herhangi bir guvenlik acigi tespit etmeniz halinde, bunu halka acik GitHub Issue uzerinden **kesinlikle bildirmeyiniz**.

Guvenlik bildirimleri icin asagidaki iletisim kanallarini kullaniniz:

- **E-Posta:** `bilgiislem@kastamonu.bel.tr` ve `arge@kastamonu.bel.tr`
- **Konu Basligi:** `[GUVENLIK BILDIRIMI] - <Ilgili Servis / Modul Adi>`
- **GitHub Ozel Guvenlik Bildirimi:** Desteklenen depolarda GitHub uzerinden "Report a vulnerability" (Advisory) butonunu kullanarak dogrudan guvenlik ekibimizle ozel iletisim kurabilirsiniz.

### Bildirimde Bulunmasi Gereken Bilgiler

1. Acikligin turu ve tahmini etki alani (CWE/CVSS siniflandirmasi).
2. Guvenlik acigini yeniden ureten adimlar (Adim adim aciklama veya PoC).
3. Etkilenen bilesenler, API uc noktalari veya surumler.
4. Varsa alinabilecek gecici hafifletme tedbirleri (workaround).

## Koordineli Aciklik Paylasimi (CVD) Politikasi

Belediyemiz 'Coordinated Vulnerability Disclosure' prensiplerini benimser:
- Bildirilen guvenlik acikliklari en gec 48 saat icerisinde Bilgi Islem Mudurlugu Siber Savunma ekibi tarafindan incelenir ve onay durumu raporlayana iletilir.
- Aciklik kapatilip uretim ortamlarina guvenlik yamasi uygulanana kadar detaylar gizli tutulur.
- Etik guvenlik arastirmacilarina ve kamu bilisim sistemlerinin korunmasina katki saglayanlara kurumsal tesekkur beyani yayimlanir.
